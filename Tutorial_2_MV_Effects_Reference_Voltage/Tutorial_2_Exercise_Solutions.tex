\section*{Before you start}
In a fresh kernel, run Sections 2.2--2.4 of
\path{Tutorial_2_MV_Effects_Reference_Voltage.ipynb}.
Then run the seven listings below in order in the Exercise Workspace.
Sections 2.5--2.6 are not needed. The listings use the notebook's existing
data and helpers.

Each fit uses 40 epochs, independently of quick/full mode. Select settings
and a seed using three training-data folds; leave the test set until E2.3.
This is same-time estimation from simulated data, not forecasting.
The exercises reuse the tutorial's test period, not a new independent test set.

\textbf{How to read this document.} Each task is followed by its recorded
output and a short explanation. Values come from the existing exercise
CSV/JSON records and may vary slightly on another run. Selection uses
unrounded scores, not the rounded values printed here. File-export code
is omitted so the listings focus on the exercise itself.

\section*{E1.1: Prepare two input sets and the same targets}
Both models use every customer's P/Q. Only the second model also receives
the three supplied Vref columns. All customer voltages remain targets.
Do not fit scalers yet; the validation helper handles this within each fold.

\begin{lstlisting}
e1_reference_columns = REFERENCE_PHASES.copy()
e1_target_customers = np.arange(1, C + 1)
e1_model_inputs = {
    "PQ_only": PQ_mv_tr,
    "PQ_plus_Vref": np.column_stack([
        PQ_mv_tr, V_secondary_mv_tr
    ]).astype(np.float32),
}
e1_targets = V_mv_tr
e1_model_names = list(e1_model_inputs)

for name in e1_model_names:
    print(MODEL_LABELS[name], "inputs:", e1_model_inputs[name].shape)
print("Targets:", e1_targets.shape)
print("Reference columns:", e1_reference_columns)
print("Target customers:", e1_target_customers.tolist())
\end{lstlisting}

epochs, folds and seed unchanged. \texttt{run\_grid\_search()} evaluates

\section*{E1.3: Choose one shared configuration}
The existing exercise rule ranks configurations by the \emph{joint score}:
the arithmetic mean of the two model-specific mean validation RMSE values.
This chooses common settings for the comparison, not separate settings
for each model. The individual scores are still reported separately.

\begin{lstlisting}
e1_results = e1_results.sort_values(
    "joint_RMSE_kfold", kind="stable"
).reset_index(drop=True)
display(e1_results[[
    "hidden_neurons",
    "PQ_only_RMSE_kfold", "PQ_only_RMSE_std",
    "PQ_plus_Vref_RMSE_kfold", "PQ_plus_Vref_RMSE_std",
    "joint_RMSE_kfold",
]].round(6))
e1_best_row = e1_results.iloc[0]
e1_best_config = {
    "hidden_neurons": int(e1_best_row["hidden_neurons"]),
    "activation": "relu",
    "lr": 1e-3,
    "weight_decay": 1e-5,
    "batch_size": 72,
    "epochs": 40,
}
print("Selected configuration:", e1_best_config)
\end{lstlisting}

\textbf{Recorded output.} Fold means and standard deviations are in volts.
\begin{center}

\toprule
Hidden & P/Q mean & P/Q std. & +Vref mean & +Vref std. & Joint \\

\section*{E2.2: Train two fresh models on all training rows}
Fit one target scaler and a separate input scaler for each input design
using all supplied training rows. Train new models with the selected
settings and seed; do not continue training validation-fold models.

% Training budget: 2 configurations * 3 folds * 2 models,
% plus 3 seeds * 3 folds * 2 models, plus 2 final models = 32 fits.
\begin{lstlisting}
e2_output_scaler = MinMaxScaler().fit(e1_targets)
e2_Y_train = e2_output_scaler.transform(e1_targets).astype(np.float32)
e2_models = {}
e2_input_scalers = {}
e2_training_rows = []
for name in e1_model_names:
    e2_scaler = MinMaxScaler().fit(e1_model_inputs[name])
    e2_input_scalers[name] = e2_scaler
    e2_X_train = e2_scaler.transform(
        e1_model_inputs[name]
    ).astype(np.float32)
    e2_model = build_model(
        e2_X_train.shape[1], C, e1_best_config,
        seed=e2_selected_seed
    )
    e2_history = train_model(
        e2_model, e2_X_train, e2_Y_train, e1_best_config
    )
    e2_models[name] = e2_model
    e2_training_rows.append({
        "Model": MODEL_LABELS[name],
        "Inputs": e2_model.input_shape[-1],
        "Outputs": e2_model.output_shape[-1],
        "Completed epochs": len(e2_history.epoch),
    })
display(pd.DataFrame(e2_training_rows))
\end{lstlisting}

\section*{E2.3: Predict test voltages and calculate errors}
Use the fitted training scalers to transform the matching test inputs.
\texttt{predict\_unscaled()} restores volts. Calculate overall RMSE/MAE
and then one RMSE for each customer, separately for each model.

\begin{lstlisting}
e2_test_inputs = {
    "PQ_only": PQ_mv_te,
    "PQ_plus_Vref": np.column_stack([
        PQ_mv_te, V_secondary_mv_te
    ]).astype(np.float32),
}
e2_test_targets = V_mv_te
e2_predictions = {}
e2_errors = {}
e2_metric_rows = []
for name in e1_model_names:
    e2_X_test = e2_input_scalers[name].transform(
        e2_test_inputs[name]
    ).astype(np.float32)
    e2_predictions[name] = predict_unscaled(
        e2_models[name], e2_X_test, e2_output_scaler
    )
    e2_error = e2_predictions[name] - e2_test_targets
    e2_errors[name] = e2_error
    e2_metric_rows.append({
        "Model": MODEL_LABELS[name],
        "RMSE (V)": np.sqrt(np.mean(e2_error ** 2)),
        "MAE (V)": np.mean(np.abs(e2_error)),
    })
e2_metrics = pd.DataFrame(e2_metric_rows)
# axis=0 averages over time, leaving one value per customer.
e2_customer_rmse = pd.DataFrame({
    "Customer": e1_target_customers,
    "P/Q only RMSE (V)": np.sqrt(np.mean(
        e2_errors["PQ_only"] ** 2, axis=0
    )),
    "P/Q + Vref RMSE (V)": np.sqrt(np.mean(
        e2_errors["PQ_plus_Vref"] ** 2, axis=0
    )),
})
display(e2_metrics.round(6))
display(e2_customer_rmse.round(6))
\end{lstlisting}

\textbf{Recorded output.} Evaluation uses 2,016 test rows and all 31 customers.
\begin{center}
\begin{tabular}{lrr}
\toprule
Model & RMSE (V) & MAE (V) \\
\midrule
P/Q only & 0.658955 & 0.479735 \\
P/Q + Vref & 0.047638 & 0.034860 \\
\bottomrule
\end{tabular}
\end{center}
The model with Vref has lower test errors in this experiment. RMSE gives
more weight to larger errors; MAE is the mean absolute error. Inspect the
customer table below as well, rather than relying only on overall scores.

\section*{E2.4: Inspect the worst P/Q-only customer}
Find the customer with the largest P/Q-only RMSE, then plot that same
customer for both models. This is inspection after training, not another
selection step. Residuals are estimated voltage minus reference voltage.

\begin{lstlisting}
e2_worst = int(np.argmax(e2_customer_rmse["P/Q only RMSE (V)"]))
e2_customer = int(e1_target_customers[e2_worst])
print("Worst P/Q-only customer:", e2_customer)
display(e2_customer_rmse.iloc[[e2_worst]].round(6))
e2_hours = np.arange(len(e2_test_targets)) * MINUTES_PER_STEP / 60
e2_fig, e2_axes = plt.subplots(2, 1, figsize=(11, 6), sharex=True)
e2_axes[0].plot(
    e2_hours, e2_test_targets[:, e2_worst],
    color="black", label="Simulated reference"
)
for name, colour in [("PQ_only", "tab:red"),
                     ("PQ_plus_Vref", "tab:green")]:
    e2_axes[0].plot(
        e2_hours, e2_predictions[name][:, e2_worst],
        color=colour, label=MODEL_LABELS[name], alpha=0.8
    )
    e2_axes[1].plot(
        e2_hours, e2_errors[name][:, e2_worst],
        color=colour, label=MODEL_LABELS[name], linewidth=0.8
    )
e2_axes[0].set_ylabel("Voltage (V)")
e2_axes[0].set_title(f"Exercise: worst P/Q-only customer {e2_customer}")
e2_axes[0].legend()
e2_axes[1].axhline(0, color="black", linestyle="--")
e2_axes[1].set_xlabel("Hours from start of test period")
e2_axes[1].set_ylabel("Estimate - reference (V)")
e2_axes[1].set_title("Voltage residuals")
e2_axes[1].legend()
e2_fig.tight_layout()
plt.show()
\end{lstlisting}
