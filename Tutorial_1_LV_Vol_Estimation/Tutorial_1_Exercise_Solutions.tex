\section*{Before you start}
In a fresh kernel, run Sections 2.2--2.4 of
\path{Tutorial_1_LV_Voltage_Estimation.ipynb}. Then run the seven listings
below in order in the Exercise Workspace. Sections 2.5--2.6 are not needed.
The listings use the notebook's existing data and helper functions.

Each fit uses 40 epochs, independently of quick/full mode. Select settings
and a seed using three training-data folds; leave the test set until E2.3.
This is same-time estimation from simulated data, not forecasting. The
exercises reuse the tutorial's test period, not a new independent test set.

\textbf{How to read this document.} Each task is followed by its recorded
output and a short explanation. Values come from the existing exercise
CSV/JSON records and may vary slightly on another run. Selection uses
unrounded scores, not the rounded values printed here. File-export code
is omitted so the listings focus on the exercise itself.

\section*{E1.1: Start with 93 hidden neurons and tanh}
Check this configuration on three blocked folds. \texttt{evaluate\_config()}
fits scalers on each fold's training rows and trains a fresh network.

\begin{lstlisting}
e1_config = {
    "hidden_neurons": 93,
    "activation": "tanh",
    "lr": 1e-3,
    "weight_decay": 1e-5,
    "batch_size": 72,
    "epochs": 40,
}
e1_seed = 42
e1_k = 3
e1_rows = []
e1_scores = evaluate_config(
    e1_config, PQ_tr, V_tr, k=e1_k, seed=e1_seed
)
# Keep this result for the comparison in E1.3.
e1_row = e1_config.copy()
e1_row.update(e1_scores)
e1_rows.append(e1_row)
print("Mean RMSE (V):", round(e1_scores["RMSE_kfold"], 6))
print("Std. (V):", round(e1_scores["RMSE_std"], 6))
\end{lstlisting}

\textbf{Recorded output:} mean validation RMSE = 0.081666 V;
standard deviation = 0.004465 V.

The mean summarises the three validation errors; the standard deviation
shows how much they differ across folds, not a confidence interval.

\section*{E1.3: Add ReLU and choose the best configuration}
Evaluate the two ReLU networks, then combine them with the stored tanh
results. Sort by mean validation RMSE so the first row is the best case.

\begin{lstlisting}
for e1_neurons in [93, 155]:
    e1_relu_config = e1_config.copy()
    e1_relu_config["hidden_neurons"] = e1_neurons
    e1_relu_config["activation"] = "relu"
    e1_relu_scores = evaluate_config(
        e1_relu_config, PQ_tr, V_tr, k=e1_k, seed=e1_seed
    )
    e1_relu_row = e1_relu_config.copy()
    e1_relu_row.update(e1_relu_scores)
    e1_rows.append(e1_relu_row)

e1_results = pd.DataFrame(e1_rows).sort_values(
    "RMSE_kfold", kind="stable"
).reset_index(drop=True)
display(e1_results[[
    "hidden_neurons", "activation", "epochs",
    "RMSE_kfold", "RMSE_std",
]].round(6))

# Only size and activation changed; keep the other settings.
e1_best_row = e1_results.iloc[0]
e1_best_config = e1_config.copy()
e1_best_config["hidden_neurons"] = int(e1_best_row["hidden_neurons"])
e1_best_config["activation"] = e1_best_row["activation"]
print("Selected configuration:", e1_best_config)
\end{lstlisting}

\section*{E2.2: Train a fresh model on all training rows}
The settings are now fixed. Fit new scalers on all supplied training
rows, then train a new network. Do not continue training a
validation-fold model.

\begin{lstlisting}
e2_input_scaler = MinMaxScaler().fit(PQ_tr)
e2_output_scaler = MinMaxScaler().fit(V_tr)
e2_X_train = e2_input_scaler.transform(PQ_tr).astype(np.float32)
e2_Y_train = e2_output_scaler.transform(V_tr).astype(np.float32)

e2_model = build_model(
    2 * C, C, e1_best_config, seed=e2_selected_seed

e2_history = train_model(
    e2_model, e2_X_train, e2_Y_train, e1_best_config

e2_model.summary()
print("Completed epochs:", len(e2_history.epoch))
\end{lstlisting}

\section*{E2.3: Predict test voltages and calculate errors}
Transform the test inputs with the fitted training scaler.
\texttt{predict\_unscaled()} converts predictions back to volts before
the errors are calculated. Do not fit either scaler on the test set.

\begin{lstlisting}
e2_X_test = e2_input_scaler.transform(PQ_te).astype(np.float32)
e2_V_estimated = predict_unscaled(
    e2_model, e2_X_test, e2_output_scaler
)
e2_error = e2_V_estimated - V_te

# Overall errors: average over all times and customers.
e2_rmse = np.sqrt(np.mean(e2_error ** 2))
e2_mae = np.mean(np.abs(e2_error))
e2_metrics = pd.DataFrame({
    "Metric": ["RMSE", "MAE"],
    "Value (V)": [e2_rmse, e2_mae],
})

# One RMSE per customer: average over time only (axis=0).
e2_customer_rmse = np.sqrt(np.mean(e2_error ** 2, axis=0))
e2_customer_errors = pd.DataFrame({
    "Customer": np.arange(1, C + 1),
    "RMSE (V)": e2_customer_rmse,
})
display(e2_metrics.round(6))
display(e2_customer_errors.round(6))
\end{lstlisting}

\textbf{Recorded output.} Evaluation uses 2,016 test rows and all
31 customers.

\begin{center}
\begin{tabular}{lr}
\toprule
Metric & Value (V) \\
\midrule
RMSE & 0.054894 \\
MAE & 0.039941 \\
\bottomrule
\end{tabular}
\end{center}

RMSE gives more weight to larger errors; MAE is the mean absolute
error. The customer table below shows whether the overall score hides

\section*{E2.4: Inspect the customer with the largest RMSE}
Use \texttt{argmax()} to find the largest customer error. Array positions
start at zero, so add one for the customer number. Plot its voltage and
residual (estimate minus reference); do not use this inspection to retune.

\begin{lstlisting}
e2_worst = int(np.argmax(e2_customer_rmse))
print("Customer:", e2_worst + 1)
print("RMSE (V):", round(e2_customer_rmse[e2_worst], 6))
e2_hours = np.arange(len(V_te)) * MINUTES_PER_STEP / 60
e2_fig, e2_axes = plt.subplots(2, 1, figsize=(11, 6), sharex=True)
e2_axes[0].plot(
    e2_hours, V_te[:, e2_worst],
    color="black", label="Simulated reference"
)
e2_axes[0].plot(
    e2_hours, e2_V_estimated[:, e2_worst],
    color="tab:blue", label="Estimated", alpha=0.8
)
e2_axes[0].set_ylabel("Voltage (V)")
e2_axes[0].set_title(f"Exercise 2: Customer {e2_worst + 1}")
e2_axes[0].legend()
e2_axes[1].plot(
    e2_hours, e2_error[:, e2_worst],
    color="tab:red", linewidth=0.8
)
e2_axes[1].axhline(0, color="black", linestyle="--")
e2_axes[1].set_xlabel("Hours from start of test period")
e2_axes[1].set_ylabel("Estimate - reference (V)")
e2_axes[1].set_title("Voltage residual")
e2_fig.tight_layout()
plt.show()
\end{lstlisting}
